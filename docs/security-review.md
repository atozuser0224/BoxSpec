## Audit boundaries still awaiting implementation

- Packaged Electron launch, navigation behavior, helper resource/signature verification and installer boundary.
- Low-disk, antivirus/lock races, forced process termination at every multi-file journal stage, and directory-entry durability limitations.
- Same-user processes are outside the authorization guarantee; no OS sandbox is claimed.
