# BoxSpec 0.1.0 Alpha 1

Windows x64용 첫 프리릴리즈입니다. AI가 먼저 박스로 화면을 구성하고, 사용자가 직접 수정한 배치를 코딩 에이전트에게 전달하는 로컬 데스크톱 앱입니다.

## 다운로드

- `BoxSpec-0.1.0-win-x64-setup-unsigned.exe`: 사용자 계정에 설치하는 실행 파일.
- `BoxSpec-0.1.0-win-x64-portable.zip`: 압축을 풀고 `BoxSpec.exe` 실행.
- `boxspec-safe-fs.exe`: 소스 개발용 파일 작업 도구. 일반 사용자는 별도로 받을 필요가 없습니다.
- `SHA256SUMS`: 배포 파일 SHA-256 체크섬.

Electron, MCP 브리지, 파일 작업 도구, Chromium과 검증용 도구가 번들에 포함됩니다.

## 포함된 기능

- AI 레이아웃 제안이 캔버스에 바로 표시되며 이동·크기 조정·그룹 편집 후 **이 배치로 구현**으로 전달됩니다.
- 출처가 표시된 17개 디자인 테마를 검색·선택하고 캔버스와 생성 UI에 적용합니다. 미리보기는 참고 디자인으로 만든 BoxSpec 자체 샘플입니다.
- SQLite 기반 저장, 실행 취소·다시 실행, 조절 가능한 패널, 로컬 MCP 클라이언트 설정을 제공합니다.
- 코드 후보 검증과 사용자 승인·적용을 분리합니다. 변경된 원본과 중단된 파일 작업은 복구 절차로 처리합니다.

## 검증 범위

- 최종 의존성 설치, 전체 빌드와 타입 검사 통과.
- 전체 패키지 테스트 168개 통과.
- 실행 파일과 브라우저·검증 도구의 변경 감지 및 원본 변경 복구에 대한 추가 보안 검사 13개 통과.
- 최종 Windows 패키징 및 Electron 실행 결과는 저장소의 `docs/evidence/packaging.md`와 `docs/evidence/e2e.md`에 기록합니다.

## 알려진 제한

이 배포본은 서명되지 않은 알파 버전이며 전체 P1 출시 기준 통과를 의미하지 않습니다. 자동 업데이트와 깨끗한 Windows VM의 설치 검증은 완료되지 않았습니다.

Codex의 실제 MCP 연결은 확인했지만 OpenCode·Claude Code의 전체 호환성은 미검증입니다. 접근성·시각 기준선 검사, 일부 파일만 승인하는 UI, Adopted Web 및 자산 인덱스의 제품 통합은 아직 완료되지 않았습니다. 지원하지 않는 검사는 PASS로 취급하지 않습니다.

원본 파일 내보내기는 수 초 걸릴 수 있으며 앱은 로컬 저장과 원본 동기화 상태를 따로 표시합니다. 임의 TypeScript/CSS에서 레이아웃을 역추론하거나 손상된 generated-manifest JSON을 자동 복구하는 기능은 지원하지 않습니다.
